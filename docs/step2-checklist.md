# Step 2 Checklist

## Что создано

- Shared design system in `assets/css/variables.css`
- Base styles in `assets/css/base.css`
- Layout styles in `assets/css/layout.css`
- Reusable component styles in `assets/css/components.css`
- Page-specific styles in `assets/css/pages.css`
- Responsive styles in `assets/css/responsive.css`
- Main import file in `assets/css/style.css`

## Параметры дизайна

- Цветовая палитра: основной тёмно-синий, синий, жёлтый акцент, светлый фон и тексты в соответствии с заданием.
- Типографика: приоритет `Kedebideri`, fallback `sans-serif`.
- Основной подход: современная академическая визуальная система с мягкими тенями, приглушёнными акцентами и структурированной иерархией.
- Глобальная цель: сохранить понятную и единообразную платформенную визуальную модель на всех страницах.

## Обнаруженные проблемы и исправления

- Требовалось подключить единый CSS-файл на каждую страницу; это сделано.
- Требовалось обеспечить корректный путь из папки `pages/` до `assets/css/style.css`; исправлено на `../assets/css/style.css`.
- Требовалось сохранить существующие HTML-структуры и ссылки; структуру не меняли, добавили только подключение CSS.
- Требовалось избегать фиктивной анимации; в проекте оставлены только лёгкие, безопасные CSS-эффекты и `transition`.

## Ограничения проверки

- Визуальная проверка в браузере не выполнялась в этой среде, поэтому окончательная оценка внешнего вида требует ручного просмотра в локальном браузере.
- Цвета, отступы и типографика были выстроены согласно требованиям и техническому заданию, но окончательная визуальная доработка и тонкая настройка возможны при ручной проверке в браузере.
