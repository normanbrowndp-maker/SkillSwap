# Обзор проекта SkillSwap

## Цель проекта

SkillSwap создаётся как платформа для обмена знаниями между студентами. Цель — сделать обучение доступным, взаимовыгодным и организованным без необходимости в платных курсах.

## Основная функциональность

- регистрация и профиль студента;
- указание навыков, которыми пользователь владеет;
- указание навыков, которые хочется освоить;
- поиск партнёров по совпадению интересов;
- демонстрация рейтинга преподавателей;
- планирование занятий и просмотр расписания;
- система SkillPoints;
- отзывы и рейтинг после завершённых сессий.

## Логика SkillPoints

SkillPoints — это внутренняя валюта платформы. Студент может:
- получать баллы за преподавание другим пользователям;
- тратить баллы на обучение у более опытных коллег;
- отслеживать историю операций в личном кабинете.

Для демонстрации используется правило: 1 час занятия = 10 SP.

## Будущие технологические этапы

1. Step 1 — HTML: семантическая структура всех страниц и демонстрационный контент.
2. Step 2 — CSS: визуальный дизайн, адаптивность и единый стиль интерфейса.
3. Step 3 — JavaScript: фильтры, модальные окна, интерактивные элементы, динамические списки.
4. Step 4 — Backend и database: регистрация, хранение данных, мэтчинг, расписание, система транзакций и отзывы.

## Ограничения текущей версии

- статические HTML-страницы без серверной логики;
- демонстрационный контент вместо реальных данных;
- отсутствие авторизации и проверки безопасности;
- отсутствие подключения CSS, JS и базы данных.
